Design a modern e-commerce website interface for a PC hardware online store called “PCOnlineShop”. The website should be inspired by the premium gaming-hardware style of Corsair’s official website, but it must not copy Corsair’s logo, images, text, branding, or exact layout. Use the same general design direction: dark theme, clean structure, large product visuals, bold typography, gaming/technology feeling, professional spacing, and category-focused navigation.

The goal is to create a high-end online shop for PC components, gaming peripherals, and PC building tools. The design should feel reliable, powerful, modern, and suitable for gamers, PC builders, students, creators, and office users who want to buy computer parts.

Use the following project context:
- Project name: PCOnlineShop
- Type: E-commerce website for PC components and accessories
- Main products: Mainboard, CPU, GPU, Memory/RAM, Storage, PC Case, Power Supply, Cooling, Keyboard, Mouse, Monitor
- Extra technical categories: Socket AM4, Socket AM5, LGA1700, LGA1200, DDR4, DDR5, PCIe 3.0, PCIe 4.0, PCIe 5.0, SATA, M.2 NVMe, ATX, Micro-ATX, Mini-ITX, E-ATX
- Main brands: ASUS, MSI, Gigabyte, Intel, AMD, NVIDIA, Corsair, Kingston, Samsung, Cooler Master, NZXT, Lian Li, Western Digital, Seagate, G.Skill

Overall visual style:
- Use a dark premium theme.
- Main background color: near-black or dark charcoal.
- Secondary background: dark gray cards and panels.
- Text color: white and light gray.
- Accent color: electric blue, cyan, or yellow-orange for buttons, active states, and important highlights.
- Use clean sans-serif typography.
- Headings should be bold, slightly condensed, and powerful.
- Product cards should have rounded corners, subtle shadows, soft borders, and smooth hover animation.
- Use large product images with clean lighting and transparent or dark backgrounds.
- The layout should be responsive for desktop, tablet, and mobile.
- The website should feel like a professional gaming hardware store, not a simple basic shop.
